# Security policy

FluxVault is early-stage software. Do not use it as the only copy of important
data until a production release is published.

## Reporting vulnerabilities

Please report security issues privately by opening a GitHub security advisory
when the public repository is available. Do not disclose exploitable issues in a
public issue before maintainers have had a reasonable chance to respond.

## V1 posture

- No hidden telemetry.
- Local logs only.
- No client-side encryption in v1.
- Repository files are plain local artefacts unless a future encrypted format is
  explicitly enabled.
- Code signing is required before public V1 installer release.
