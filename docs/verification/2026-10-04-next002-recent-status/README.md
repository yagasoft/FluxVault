# Bounded recent history for Overview

This S2 batch removes a confirmed unnecessary complete-history read from Overview. Its existing fifty-version window now uses a parameterised, indexed PostgreSQL query before manifest loading/decoding. Repository binding, manifest size/identity validation and status-cache identity/generation checks remain. Full history/current-file paging, large-scale latency/resource measurements, other S2 work, final G01 and normal installation rollout remain open. No roadmap or architecture expansion is implied.

Fresh staging metadata is schema version 2. Exact UTC ticks are written with each immutable manifest in the existing transaction; a descending tick/ordinal-ID index preserves the previous .NET ordering at a 100 ns boundary. Every selected manifest must match both SQL ordering keys exactly. Existing unsupported namespaces are refused before schema mutation; no automatic backfill, upgrade or data adoption occurs. Retain v1.0.4 and its database/storage assets for recovery. The filesystem/developer fallback still loads complete history; protected Windows service metadata uses the bounded query. No new user-facing setting or history-window size is introduced.
